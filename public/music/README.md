# مجلد الموسيقى والمقاطع الصوتية (Music Folder)

ضع جميع ملفات الموسيقى الخاصة بك هنا بصيغ:
- `.mp3`
- `.wav`
- `.m4a`
- `.ogg`
- `.aac`
- `.flac`

سيقوم التطبيق تلقائياً بقراءة كل ملفات الصوت الموجودة في هذا المجلد وتنسيق أسمائها وإضافتها لمشغل الموسيقى، حتى عند إضافة أو تعديل أو حذف أي ملف مستقبلاً.
